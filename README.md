# I'm HAPPY · 안드로이드 테스트 빌드 0.1.0

React Native(Expo SDK 57)로 만든 I'm HAPPY 테스트 앱이에요. 이 프로젝트에서 APK를 만드는 방법은 두 가지예요.

## 방법 1. Expo EAS로 만들기 (가장 쉬움)

PC에 Node.js(22 이상)만 있으면 돼요. Android Studio는 필요 없어요.

1. [expo.dev](https://expo.dev)에서 무료 계정을 만든다.
2. 이 폴더에서 터미널을 열고 아래를 차례로 실행한다.
   ```sh
   npm install
   npx eas-cli@latest login
   npx eas-cli@latest build -p android --profile preview
   ```
3. 처음 실행하면 프로젝트 연결과 서명 키 생성을 물어요. 모두 기본값(Enter)으로 진행한다.
4. 10~20분 뒤 터미널과 expo.dev에 APK 다운로드 링크와 QR 코드가 나와요. 휴대폰으로 열어 설치한다.

## 방법 2. GitHub에서 자동으로 만들기

1. GitHub에 비공개 저장소를 만들고 이 폴더를 올린다 (`node_modules` 제외, `.gitignore`에 이미 들어 있음).
2. `main` 브랜치에 올리면 `.github/workflows/build-apk.yml`이 자동으로 실행된다.
3. 저장소의 **Actions** 탭 → 최근 실행 → 맨 아래 **Artifacts**의 `imhappy-apk`를 받아 압축을 풀면 APK가 있다.

이 방법의 APK는 테스트용 공용 서명 키로 서명돼요. 본인 휴대폰 테스트용으로만 쓰고 배포하지 마세요.

## 휴대폰에 설치하기

- APK를 열면 "출처를 알 수 없는 앱" 설치를 허용할지 물어요. 해당 앱(파일 관리자나 브라우저)에 한해 허용한다.
- 처음 실행하면 가입 4단계가 나와요: 대화 AI 선택 → API 키 → 잠금 PIN → 알림 허용.

## AI 연결 (테스트 빌드 전용 방식)

- 가입이나 설정에서 고른 AI의 **API 키**를 넣으면 해피가 실제로 답해요. 키를 비워두면 시연 문장으로 답해요.
- 키 발급: Claude는 console.anthropic.com, ChatGPT는 platform.openai.com, Gemini는 aistudio.google.com.
- 기본 모델: `claude-haiku-5-5`, `gpt-6-luna`, `gemini-3.6-flash` (2026년 10월 기준). 설정에서 바꿀 수 있어요.
- 키는 휴대폰의 보안 저장소(SecureStore)에만 보관돼요.

> 출시 버전에서는 반드시 키를 서버(Supabase Edge Function 등)로 옮겨야 해요. 앱 안에 키가 있으면 누구나 꺼내 쓸 수 있어요.

## 이 빌드에 들어 있는 것

| 기능 | 동작 |
| --- | --- |
| 메인 화면 | 흰 바탕 + 파스텔 글로우 로고, 해피의 물음, 입력창. 답하면 그날의 일기 대화로 넘어감 |
| 컬러 | 8색(옐로우·핑크·블루·베이지·퍼플·와인·그린·오렌지)이 다시 접속할 때마다, 켜둔 채 10분마다 바뀜 |
| 일기 날짜 | 하루의 경계는 08:30. 새벽 메시지는 전날 일기로 들어감 |
| 아침 안부 | 매일 08:30 알림. 어제 대화에 이어지는 물음 (첫날은 "반가워요 해피") |
| 일기 마감 | 다음 날 08:30 이후 앱을 열면 지난 일기를 마감하고 AI가 요약·기분을 정리 |
| 캘린더 | 날짜별 일기 요약과 대화 원문 (마감된 날은 읽기 전용) |
| 자리비움 잠금 | 1·5·10분 동안 화면을 안 만지거나, 그 이상 백그라운드에 있다 돌아오면 PIN 잠금 |
| 안전 모드 | 위험 표현은 AI 호출 전에 차단, AI가 `[SAFETY]`를 내도 전환. 109 안내, 요약·안부에서 제외 |
| 대화 AI 변경 | 설정에서 Claude·ChatGPT·Gemini 전환, 다음 메시지부터 적용 |
| 안부 시간 변경 | "준비 중" 요청 버튼만 있음 |
| 기록 지우기 | 일기·설정·키 전체 삭제 |

## 테스트 빌드의 한계

- **08:30 안부 알림 문구는 앱을 마지막으로 닫을 때 정해져요.** AI가 만든 맞춤 안부는 앱을 열었을 때 화면에 나와요. 출시 버전에서는 서버가 08:00에 만들고 08:30에 푸시를 보내요.
- **알림 시각은 몇 분 늦을 수 있어요.** 안드로이드 배터리 절약 정책 때문이에요. 정확한 시각이 필요하면 출시 전에 정확한 알람 권한을 추가한다.
- **일기는 이 휴대폰에만 저장돼요.** 앱을 지우면 함께 사라져요. 서버 동기화는 출시 버전 과제예요.
- AI 답변은 한 번에 표시돼요(글자가 흘러나오는 효과 없음).
